# Sample output

These files show the plain-text and Markdown formats produced by the module.
Names, addresses, dates, device identifiers and client details are fictional.

Keep generated structure unchanged when updating a sample. If a value needs
to be sanitised, replace only that value and retain the original headings,
status values and row count.

The Windows and tenant-backed commands should be captured from a lab machine
or test tenant. The sample files are not evidence of a production run.
